# clavenar-typescript-sdk — agent-side wrapper SDK (npm `@clavenar/agent-sdk`): inspects every tool call before it runs

## Build, test, lint
```sh
pnpm install --frozen-lockfile
pnpm build        # tsup → dist/{index.mjs, index.cjs, index.d.ts}
pnpm test         # vitest run
pnpm lint         # eslint .
pnpm typecheck    # tsc --noEmit
```
CI (`.github/workflows/ci.yml`) runs `install → lint → typecheck → test → build` on node 18/20/22. `prepublishOnly` reruns the full chain.
Run: library, no binary. Public entry `clavenarWrap(client, opts)`. No listener — it POSTs each tool call to the configured clavenar-lite ingress (`POST {endpoint}/mcp`; lite default `:8088`). E2E tests POST to `CLAVENAR_E2E_ENDPOINT`.

## Layout
- `src/index.ts` — public surface (all re-exports live here).
- `src/wrap.ts` — `clavenarWrap`: the transparent `Proxy`, structural client detection, response interception.
- `src/anthropic.ts` / `src/openai.ts` — provider-shape types + tool-call normalizers. No provider import; shapes are mirrored and narrowed.
- `src/realtime.ts` — standalone OpenAI Realtime helper (inspects `response.function_call_arguments.done`).
- `src/transport.ts` — `inspectToolUse` / `pollPendingOnce`: `POST /mcp` JSON-RPC, retry/backoff, correlation-id capture.
- `src/stream.ts` — streaming inspection; holds the close event until clavenar returns a verdict.
- `src/errors.ts` — `ClavenarDenied` / `ClavenarPending` / `ClavenarConfigError` / `ClavenarTransportError`.
- `src/devmode.ts` — `renderDenyPanel` (stderr deny panel).
- `src/types.ts` — `ClavenarOptions` + wire types.
- `tests/*.test.ts` — vitest; `e2e.test.ts` skips unless `CLAVENAR_E2E_ENDPOINT` is set.
- `examples/` — native Anthropic/OpenAI + framework integrations (langchain-js, mastra, vercel-ai, openai-realtime, computer-use). `dist/` is generated by tsup — never hand-edit.

## Conventions & invariants
- **Throw on any uninspected path.** This is the reference agent-SDK behavior, shared 1:1 with the Python sibling: if a tool call cannot be inspected, the SDK throws rather than letting it through. Provider `.stream()` convenience helpers (`messages.stream()`, `chat.completions.stream()`) are **blocked** with `ClavenarConfigError` — their rich event interfaces can't be wrapped faithfully and would bypass inspection. Only `create({ stream: true })` is inspectable; `allowUninspectedStream: true` is the explicit, documented opt-out.
- **Verdict → outcome.** `enforce` (default) + deny → throw `ClavenarDenied`; `enforce` + pending → throw `ClavenarPending` (`await e.resolve()` polls HIL, returns void on allow or throws on deny/timeout); `observe` → response passes through and `onVerdict` fires. `observe` is the rollout knob.
- **Structural detection, once at wrap time.** `messages.create` ⇒ Anthropic, `chat.completions.create` ⇒ OpenAI; every other property (`beta`, `models`, subclasses) passes through the `Proxy` unchanged. Anything unrecognized is rejected with `ClavenarConfigError`.
- **No provider runtime dependency.** `@anthropic-ai/sdk` and `openai` are optional peer deps — never turn either into a hard import. Mirror upstream shapes in `anthropic.ts` / `openai.ts` / `realtime.ts` and narrow `unknown` at the boundary.
- **Wire.** `POST {endpoint}/mcp`, JSON-RPC 2.0 `tools/call`. The provider tool-call id (`toolu_*` / `call_*`) round-trips verbatim as the JSON-RPC `id` so one ledger lookup correlates back to the model's call. `200`/`403` are verdicts and never retry; network errors + `5xx` retry with jittered exponential backoff (default 3 attempts); other `4xx` are config errors and never retry.
- **`devMode` / verbose-verdict `detail` is an attacker oracle** — dev/staging only. The SDK trusts the endpoint at `opts.endpoint`; a reachable but hostile ingress can silently allow denied calls.

Coding standards (TypeScript):
- Strict everywhere: `tsconfig` enables `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `verbatimModuleSyntax`. `typecheck` must pass clean.
- ESM with explicit `.js` specifiers on relative imports (e.g. `./wrap.js`) — keep the extension.
- ESLint flat config = `js.recommended` + `typescript-eslint` recommended + `eslint-config-prettier` last; `lint` must be clean in CI. `@typescript-eslint/no-explicit-any` is `warn` (boundary narrowing of provider `unknown` is intentional) — don't introduce new `any` without cause.
- Tests colocated in `tests/` as `*.test.ts`; keep e2e env-gated so the suite runs offline.
